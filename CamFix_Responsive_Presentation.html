Domain Services & Transactional Logic

BookingService State Machine
  • Atomic progression: REQUESTED -> ASSIGNED -> ARRIVED -> QUOTE_PENDING -> IN_PROGRESS -> COMPLETED.

KhqrService & KhqrCodec
  • Dynamic EMVCo QR code string synthesis embedding merchant ID (camfix@aba).

OtpService Multi-Channel Engine
  • Generates cryptographic 6-digit random codes with 300s TTL and 5-attempt ceiling.
  • Provider fallback: Twilio SMS -> TextBelt SMS -> Gmail SMTP TLS Email.
  • Development bypass switch (APP_OTP_EXPOSE_CODE) for automated testing passkeys.
TechnicianSelfService & Telemetry
  • High-throughput GPS coordinate ingest into technician_live_locations table.
  • Streams National ID cards and face selfie photos directly into LONGBLOB storage.

Security Architecture & AuthSupport

Stateless token validation, role-based authorization, and caller resolution helper
Shared Caller Resolver (AuthSupport.java)
@Component public class AuthSupport { private final JwtService jwtService; private final UserRepository userRepository; public Users currentUser(String authHeader) { String email = jwtService.extractEmail( bearer(authHeader)); if (email == null) throw new InvalidCredentialsException(); return userRepository.findByEmail(email) .orElseThrow(() -> new UserNotFound()); } }
Defense-in-Depth Specifications
  • Stateless HMAC-SHA256: Tokens signed with 256-bit server secret; 24-hour expiration (86,400s).
  • Role-Based Access Control: Strict isolation across ROLE_CUSTOMER, ROLE_TECHNICIAN, and ROLE_ADMIN.
  • SwaggerConfig & CORS: Permits calls from https://camapp.store and *.camapp.store while native mobile bypasses CORS.
  • GlobalExceptionHandler: Translates domain errors into clean HTTP status codes (401, 403, 404, 502).
SPRING BOOT BACKEND DEEP DIVE

Spring Data JPA & Hibernate 7 Persistence

Relational schema design, connection pooling, and verbatim column naming strategies
Exact Casing Strategy
  • PhysicalNamingStrategyStandardImpl enforces verbatim mapping of mixed-case columns.
  • Guarantees column casing match: Userid, Full_name, DateofBirth, has_password.
  • Zero database mismatch against existing production tables.
HikariCP High-Throughput Pool
  • Maximum pool size: 10 connections; Minimum idle: 5 connections.
  • Delivers sub-15ms database query response times for concurrent mobile location streams.
  • Prevents thread starvation under high booking concurrency.
In-Database LONGBLOB Storage
  • Stores National ID cards, facial selfies, and banners directly as binary data in MySQL.
  • 5MB multipart upload ceiling configured in application.properties.
  • Eliminates external cloud bucket costs during initial rollout.
18 Spring Data JPA Repositories
  • Derived query methods (findByEmail, findByJobId, findByTechnicianId).
  • Geospatial indexing on technician_live_locations.last_update for fast proximity queries.
  • Transactional boundaries ensure atomic execution.
FINANCIAL GATEWAY

NBC Bakong KHQR Settlement Lifecycle

National Bank of Cambodia open API integration, MD5 validation, and bank deep linking
1. Dynamic EMVCo QR Synthesis

Backend generates standard EMVCo string embedding merchant ID (camfix@aba), amount, currency (USD/KHR), and accepted quote ID. Generates cryptographic MD5 checksum.

2. Multi-Bank Native Launch

Mobile app detects installed banking apps. Automatically constructs native intent/URL schemes for ABA Mobile, ACLEDA Pay, and Bakong for 1-tap app switching.

3. Real-Time Settlement Polling

Mobile client initiates high-frequency 3-second background polling cycle. Backend queries Bakong Open API endpoint to verify transaction settlement status.

4. Digital Receipt & SLA Transition

Upon confirmation, backend locks transaction, transitions booking to COMPLETED, and issues digital VAT invoice to customer profile with zero dispute ambiguity.
